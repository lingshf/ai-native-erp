# AI Native ERP v0.17.0

> 发布日 2026-11-23。tag `v0.17.0`（annotated，tag 对象 `f820579c07dff7a2bbbe12efcb015796eca2e0dd`）指向 `b874b1c`（[#286](https://github.com/lingshf/ai-native-erp/pull/286) 的最终头，位于 `release/v0.17.0` 分支上，D484 / D494）；main 上的 #286 squash 提交 `d519bb4` 不是 tag 目标。产品代码基线为 main `1638445`（REFAC-09 [#285](https://github.com/lingshf/ai-native-erp/pull/285)；S18 的三项开发任务全部已合并，该提交的 main Full run 45281272956 绿）；`git diff --name-only 1638445 b874b1c -- packages scripts` 为空（已核对）。Release：<https://github.com/lingshf/ai-native-erp/releases/tag/v0.17.0>。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 minor（0.16.0 → 0.17.0）：TLIST-02 让贸易主数据页多了一个按钮，是用户可见的小功能。**无迁移，无依赖变化**，已有账套不需要 migrate，不改过账规则与任何金额、数量口径。

## 亮点

- **贸易主数据列表多一个“刷新列表”按钮**（TLIST-02，[#284](https://github.com/lingshf/ai-native-erp/pull/284)）：在“新增配置”之后（英文 “Refresh list”），五类对象都有。点它按当前公司、类型与搜索词从第一页重新读取；搜索词、所选类型和正在编辑的内容保留，不弹确认，编辑器打开时仍可用。Tab 顺序多一站。
- **发票列表内部拆分**（REFAC-09，[#285](https://github.com/lingshf/ai-native-erp/pull/285)）：`InvoiceList` 由 294 行拆成 86 行的文件与 4 个新文件，只搬移，界面与行为不变。
- **Demo 脚本缺 dist 时明确报错**（RUNMAIN-01，[#283](https://github.com/lingshf/ai-native-erp/pull/283)）：新增 `scripts/demo/assert-web-dist.ps1`，不改产品代码。
- **预付 / 贷项 / 纠错页内部修正**（FIX-TADJ-BUSY，`runAction` 结束时无条件清除“忙碌”状态；[#278](https://github.com/lingshf/ai-native-erp/pull/278)）：无用户可见变化，条目见 CHANGELOG。

## 需要注意

- **无需 migrate。** v0.16.0 的账套可直接使用。
- **体积 1（#284，D432 口径）**：产物为 Vite 构建的 `index.js` 首屏块与 `TradeMaster` 路由块；方法为 gzip-9（哈希文件名遮蔽后），base 与 head 各在新建的分离 worktree 构建；首屏 JS 160919 → 160933 B（**+14 B**，上限 +40 B），`TradeMaster` 路由块 4572 → 4658 B（**+86 B**，上限 +200 B）；来源：#284 正文“L10 打包”。
- **体积 2（#285，D432 口径，D476 预算 +900 B）**：产物为发票页路由 `src/TradeInvoices.tsx` 的 route-added JS；方法为 gzip-9（哈希文件名遮蔽后）；21939 → 22365 B（**+426 B**）；首屏块 raw 530584 → 530584 B（±0）；来源：[#285 评论 3](https://github.com/lingshf/ai-native-erp/pull/285#issuecomment-7115662750)、[评论 15](https://github.com/lingshf/ai-native-erp/pull/285#issuecomment-7115931144)。
- **体积 3（#278）**：产物为 `TradeAdjustments-*.js`；方法为 gzip-9，clean worktree；6285 → 6282 B（**−3 B**）；来源：#278 正文 F6。
- **证据口径**：REFAC-09 的“行为不变”靠 #285 的 R4（10 个场景 base 与 head 逐字节相同），是 jsdom 证明；TLIST-02 的 L2–L7 是 jsdom 用例，不模拟按键。真实 Chrome 的原生键盘与 390 px 排布见 Demo。
- **真实 Chrome（Demo，R3 时段，端口 4203，退出码 0，23 项显式检查全部通过，另有 9 条取证记录）**：贸易主数据页在 1440 下列表有行、无横向溢出；键盘：焦点从“New configuration”按 Tab 到“Refresh list”，Enter 与空格各触发 1 次列表请求，编辑器打开时（“New configuration”禁用）Tab / Enter 同样 1 次请求，编辑器仍打开。390 宽：`scrollWidth` 390，贸易主数据两个按钮、英文订单页与发票页三个按钮都在视口内、同一行。产物：`capture-log-real.json`；方法：`capture.mjs` 在真实 Chrome 下记录（`page.keyboard.press`）；来源：[docs/demo/v0.17.0](../demo/v0.17.0/README.md)。
- 数字（行数、用例数、场景数、体积）取自各来源 PR 正文，发布前未重测。
