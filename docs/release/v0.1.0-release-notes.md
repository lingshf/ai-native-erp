# AI Native ERP v0.1.0（预览）— Release 说明草稿

> 草稿，待协调者授权后创建 tag 与 GitHub Release。标题标为 **pre-release / 预览**。按 D21，tag `v0.1.0` 打在 #51 合并后的 squash 提交上。产品代码基线是 `d8fa0bb`；此后 main 只有文档提交（#50、#52），产品代码与 d8fa0bb 相同。打 tag 前请再核对该提交相对 d8fa0bb 无产品代码变更。CHANGELOG 日期为 2026-11-19。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

## 亮点

- 完整的核心账务：科目、财务维度、凭证（草稿/预览/确认/镜像纠错）、业务事件与队列、总账报表与下钻、期末结账。
- 候选式 AI 助手：只起草和讲解，绝不自动记账。
- 贸易 AP/AR 预览：主数据、采购/销售发票、付款/收款与现金折扣、预付/预收、贷项与专用纠错。
- 备份/恢复命令；旧账快照命令（须授权）。
- 教学说明开关，默认关闭，不改变会计规则。

## 预览说明与已知限制

- 贸易功能未完整：缺未结项/账龄/GL 核对（M1-06）与端到端验收（M1-07）。
- 内置科目不含 AP/AR/税控制科目；使用贸易前需自行建立。
- M2 旧账：仅快照命令可用；导入映射/dry-run 无入口；导入执行未发布。
- “只读报表 → 试算平衡表”读取旧快照；未配置时该入口返回 503，提示“已验证快照不可用或未配置。请检查服务后重试。”——这是当前提示，不代表当前账套不可用，请改用“总账报表”。
- 凭证页列表为空时误显示“没有科目。”，并非科目缺失（后续修复）。
