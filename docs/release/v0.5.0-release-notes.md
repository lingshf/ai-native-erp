# AI Native ERP v0.5.0

> **发布候选草稿**：发布日期待定，未获打 tag 授权。产品代码基线为 main `6c8724b`（S5 全部合并，Full 12/12）；自 v0.4.0（tag 所指提交 `b3b3fb7`）起共 17 个提交，`packages/` 的变化只在 `packages/web/src`（样式、焦点时序、迁移核对页表格容器）与测试，其余是文档与设计提交（#110、#111、#114、#116、#119、#124）。按 D21，tag `v0.5.0` 打在发布 PR 合并后的 squash 提交上。完整变更对比：[v0.4.0...v0.5.0](https://github.com/lingshf/ai-native-erp/compare/v0.4.0...v0.5.0)（tag 创建后生效）。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 minor（0.4.0 → 0.5.0）：少量用户可见改进，无不兼容变化，无新增迁移。

## 亮点

- **焦点更早到位**：保存订单后，焦点在提示出现的同一次提交中就落到提示上（#117）；凭证打开草稿、保存、查看、确认过账、确认删除之后，以及业务事件点“查看”后，焦点同一刻到位（#123，FOCUS-01）。读屏用户更早听到；最终焦点位置不变。
- **迁移核对页的键值表**不再超出折叠区右缘，窄屏在表格自己的区域内横向滚动（#112）。页面仍只读。
- **`styles.css` 全局元素规则改为页面类 / 组件规则**（S5，D-7）：用户看不到变化，各 PR 的截图与计算值对照均为 0 像素差。**D-7 只完成了一部分**：还有 4 项全局规则保留，设计正在登记为 backlog（见“已知限制”）。
- **触控尺寸的来源变了，高度没变**：全局 `button, select { min-height: 44px }` 已删除（#126），触控尺寸由各组件和页面类规则提供。
- **FLAKE-02 诊断**：贸易 GUI E2E 的偶发失败增加了定向诊断，**默认关闭**，设置 `ERP_E2E_DIAG=1` 开启（#121）。这是测试支持代码，不影响产品；原因仍未知。

## 与 v0.4.0 相比的显示变化（旧 → 新）

| 位置 | v0.4.0 | v0.5.0 |
| --- | --- | --- |
| 迁移核对页键值表 | 比折叠区右缘多出 8px；窄屏页面可能被撑宽 | 在自己的滚动区内，左右对称、比原来窄 16px；窄屏表内横向滚动；390px 下个别单元格可能多折一行 |
| 保存订单后的焦点 | 提示出现后 3.6–28.3 ms 才移到提示（真实 Chrome 测量，#117） | 与提示在同一次提交中落到提示上；最终位置不变 |
| 凭证 / 业务事件的焦点（#123 所列路径） | 晚一个任务到位 | 状态提交的同一刻到位；最终位置不变 |
| 按钮、选择的触控最小高度 | 来自 `styles.css` 的全局 44px 基线 | 来自 `.btn`、`.ui-field select` 等各组件和页面类规则；**实际高度不变**（155 张截图像素差 0） |

面向调用方（HTTP API、CLI、日志、端口、迁移编号）：**未变**。依据：`git diff v0.4.0 main -- packages` 中没有 API、CLI、迁移或依赖文件，只有 `packages/web/src` 与测试。

## 已知限制

- **旧账迁移（M2）仍未完成**：M2-05（演练）与 M2-06（切换）未开始，另需用户授权；迁移核对页只读，核对通过不等于允许切换。
- 真实迁移演练时，用户需提供期初未结明细文件（导入范围含 AP/AR 控制科目时必须）；期初未结项不能开贷项或取消（D30）。
- 订单页仅限非库存订单；导入、核对确认与备份 / 恢复仍是命令行。
- **D-7 只完成了一部分，4 项全局规则保留**：`button:active` 背景（`.btn-primary` 无 `:active` 规则）；概览加载失败的重试按钮样式；财务维度列表里 `label.ui-master-hit` 内复选框的尺寸与强调色；VirtualRows 超过 100 行时占位行 `td` 的 `border-bottom` / `vertical-align` / `min-width`。这些在已采集状态里删除后也是 0 差，但源码检查发现它们在未采集状态里仍生效，所以保留（#126）。
- 已登记、本版未处理：业务事件“待转队列”操作列按钮可能截成“…”（UI-11a）；业务事件主数据保存失败后焦点晚一帧（FOCUS-02）。两项在 v0.4.0 已存在。
- FLAKE-02：期末月份下拉轮询偶发为空与 `afterAll` teardown 超时，**原因未知**，本版只增加诊断，不算已修复。
- 触控尺寸：v0.4.0 的 36px / 44px 范围限制仍然有效，本版没有新增真机粗指针测量。
- “未被样式覆盖的 button / select 最小高度基线为 44px”这一说法在 v0.4.0 的发布说明与 CHANGELOG 中出现过，v0.5.0 起不再成立（机制变了，高度没变）；仓库内文档已更正。
- 本版没有新的 Demo 截图包：v0.4.0 的 [Demo](../demo/v0.4.0/README.md) 仍可参考；v0.5.0 Demo 在发布候选合并后另行准备。
