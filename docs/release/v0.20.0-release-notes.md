> 发布日 2026-11-23。tag `v0.20.0`（annotated，tag 对象 `97e9a23d2a3f78cda15bd1601ab2b0233779adc3`）指向 `90c762f05de39723852d1a381058301cab4da997`（[#310](https://github.com/lingshf/ai-native-erp/pull/310) 的最终头，位于 `release/v0.20.0`，D484）；main 上的 squash 提交 `2ce7821000066d73a563de16a9d9f8601e704495` 与它树相同。RC 范围终点固定为完整 SHA `a1a12448207372d6792b2497da852d08418c552b`（[#309](https://github.com/lingshf/ai-native-erp/pull/309)）。v0.19.0 的 tag 指向 `10292ede0906f96d26806bdd9bb7e8b4e72279c8`（`release/v0.19.0`），不在 main 上；`git diff --name-only 10292ede0906f96d26806bdd9bb7e8b4e72279c8 6156759c2aef6b9805aca70ba5505490e2bd4c5b -- packages scripts` 为空。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 minor（0.19.0 → 0.20.0）：TLIST-05 让业务事件和转账队列多了一个按钮，是用户可见的小功能。**无迁移，无依赖变化**，已有账套不需要 migrate，不改过账规则与任何金额、数量口径。

## 亮点

- **业务事件与转账队列多一个“刷新列表”按钮**（TLIST-05，[#301](https://github.com/lingshf/ai-native-erp/pull/301)）：英文 “Refresh list”，只重读第一页；草稿编辑器打开时仍可用，刷新不会清空草稿。Tab 顺序多一站。设置视图不变。
- **开发工具与测试**：SLOT-04（[#304](https://github.com/lingshf/ai-native-erp/pull/304)）槽位运行脚本；FLAKE-08（[#303](https://github.com/lingshf/ai-native-erp/pull/303)）修复 `ledger-reports` 测试的偶发失败。均无用户可见变化。
