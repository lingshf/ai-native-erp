# AI Native ERP v0.13.1（发布说明草稿）

> **草稿，未发布。** 发布日、tag 目标由协调者授权后确定。产品代码基线为 main `48ba245`（REFAC-06 [#242](https://github.com/lingshf/ai-native-erp/pull/242) 的合并提交；main Full run 45211228377 绿）。自 v0.13.0 的 tag（`9866728`）起，`packages/` 下共 29 个文件（+2765/−2651），`scripts/` 下无变化。**tag 目标**按 D21 / D398：只有 `git diff 48ba245 <目标> -- packages scripts` 为空，才可打在 RC / Demo PR 的 squash 提交上。完整变更对比：v0.13.0...v0.13.1（打 tag 后补链接）。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 patch（0.13.0 → 0.13.1）：**本版没有用户可见的功能变化**，只有代码结构整理和一处加载体积变化；**无迁移**（仍为 019），无依赖变化，不改过账规则。

## 亮点

- **没有用户可见的功能变化。** 界面、文案、行为、API、CLI 都与 v0.13.0 相同。
- **业务事件、总账报表、期末结账、贸易报表四页少加载凭证页代码**（REFAC-04，#240）：这四个路由不再带上凭证页的代码。路由新增 JS（屏蔽哈希后的 gzip-9，取自 PR 正文）：业务事件 −7320 B、总账报表 −9145 B、期末结账 −9144 B、贸易报表 −9144 B，约 7.3–9.1 KB；其余 10 个路由 ±0。
- **订单页、发票页的源码按职责拆分**（REFAC-05 #238、REFAC-06 #242）：只搬移，不改行为；DOM、文案键、类名、样式不变。

## 需要注意

- **体积代价（D453 例外）**：凭证页路由新增 JS +1017 B（原共享块拆成多块后 gzip 失去冗余），首屏入口 +63 B 原始 / +13 B gzip-9。订单页 +59 B（D432 预算 +200 B 内）；发票页的 5 条路由各 −23 B（gzip-9）；REFAC-06 对首屏入口的影响是 +3 B（文件名哈希屏蔽后经 gzip-9 压缩测得；D454 视同 ±0），这是两个不同的数字。数字取自 PR 正文，发布前未重测；与 v0.13.0 相比的整体净变化未单独测量。
- 本版没有改变任何用户操作，升级后不需要重新学习界面。
