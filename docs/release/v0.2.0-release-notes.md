# AI Native ERP v0.2.0 — Release 说明草稿

> 草稿，待协调者授权后创建 tag 与 GitHub Release。M1 完成，不再标预览。按 D21，tag `v0.2.0` 打在本发布 PR 合并后的 squash 提交上；产品代码为 main 自 v0.1.0（`0930979`）以来的 #49、#47、#53、#54、#56，#57 仅为评审文档。CHANGELOG 日期 2026-11-19。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

## 亮点

- **M1 贸易 AP/AR 完成**：新增“往来未结项与账龄”页——未结项、账龄、月末历史余额、全公司 GL 核对，可下钻到单据与凭证。
- **期间 trade/tax 准入**：新期间默认不准入，需在“期末结账”页显式开启才能过账贸易单据。
- **旧账导入命令（M2-03，命令行）**：导入后为 `imported`，核对前不能作为活动库。
- 体验修复：空凭证列表文案；旧快照未配置显示中性提示。
- 贸易 GUI 主路径与键盘 E2E 验收（中/英 × 红/绿）；贸易 HTTP 基准全部达标。

## 已知限制

- **Full 有一片约 147 s**（run 44551649788），超出 D15 的分片耗时目标（≤ 25 s）；R6 #55 正在处理。不影响用户功能。
- **旧账迁移（M2）尚未完成**：M2-03b、M2-04、M2-04b、M2-05 按 D25/D26 依次推进。在此之前，导入的旧账 AP/AR 余额不是未结项，核对中列为“其他来源”差额，也不能核销。
- **真实迁移演练时，用户需提供期初未结明细文件**（旧账没有子账）。
- 非库存订单只有 API；教学提示未覆盖付款、调整、主数据、期间准入页。
- 保存期间准入成功后提示措辞沿用“原操作已成功…”。
