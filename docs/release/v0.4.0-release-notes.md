# AI Native ERP v0.4.0 — Release 说明草稿

> 草稿，待协调者授权后创建 tag 与 GitHub Release。基于 main `f90d6f2`（S4 已合并 #86–#103，自 v0.3.0 `06255c7` 起 20 个提交）。**UI-10a、UI-09g 尚未合并，合并后补条目。**按 D21，tag `v0.4.0` 打在本发布 PR 合并后的 squash 提交上。日期待发布时填写。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

## 亮点

- **采购 / 销售订单录入页**（M1-R1a）：非库存订单终于有界面（此前只有 API）。金额由服务端计算，保存后显示；订单不过账、不生成凭证。
- **按伙伴代码筛选未结项**（M1-R2b）：预付 / 贷项 / 专用纠错页，服务端筛选。
- **更多教学提示**（M1-R2a、UI-10e）：付款与收款、预付 / 贷项 / 纠错、贸易主数据、期间准入说明、迁移核对（“核对通过 ≠ 批准切换”）。
- **界面细节统一**：只读“启用”列改为徽标；凭证列表操作列有表头且按钮为“查看 / 编辑”；窄屏顶栏只显示品牌图标；桌面控件统一为 36px（窄屏 / 粗指针仍为 44px）；表格链接、凭证编辑器、分段控件、滚动阴影等样式修正；发票“新增行”显示快捷键徽标。
- **迁移核对页**以“字段 / 快照预期 / 目标实际 / 差额”键值表展示差异，原始 JSON 默认折叠；页面仍只读。
- 期间准入保存提示改为“贸易期间准入已保存。”。

## 已知限制

- **旧账迁移（M2）仍未完成**：M2-05（演练）与 M2-06（切换）未开始，另需用户授权；迁移核对页只读，核对通过不等于允许切换。
- 真实迁移演练时，用户需提供期初未结明细文件（导入范围含 AP/AR 控制科目时必须，即使各科目都声明为 empty）；期初未结项不能开贷项或取消（D30）。
- 订单页仅限非库存订单，不含库存与收货。
- 导入、核对确认与备份 / 恢复仍是命令行。
- 36px 控件的证据只覆盖桌面细指针；粗指针下仍为 44px，未单独验证粗指针桌面。
- v0.3.0 的截图仍反映旧界面；v0.4.0 的 Demo 与新截图待 UI-10a / UI-09g 合并后补充。
