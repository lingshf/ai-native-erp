# AI Native ERP v0.11.0

> **发布候选草稿，发布日待定。** 产品代码基线为 main `68620fd`（Full run 45114359894 绿）：S11 功能全部结案——TINV-06 [#199](https://github.com/lingshf/ai-native-erp/pull/199)（修复 [#200](https://github.com/lingshf/ai-native-erp/pull/200)）、UI-14 [#197](https://github.com/lingshf/ai-native-erp/pull/197)。自 v0.10.0（tag 所指提交 `ae4fbaa`）到 `68620fd` 为 #193–#202。**tag 目标待定**：按 D335 的做法打在 Demo PR 的 squash 提交上，并以 `git diff 68620fd <tag 目标> -- packages` 为空为准；定稿时本段改为实际提交。完整变更对比：[v0.10.0...v0.11.0](https://github.com/lingshf/ai-native-erp/compare/v0.10.0...v0.11.0)。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 minor（0.10.0 → 0.11.0）：新增用户可见功能（发票详情对话框）与侧栏分组；无迁移、无契约变化。

## 亮点

- **发票详情对话框**：发票列表的“外部单号”是按钮，点击、Enter 或空格打开只读详情：抬头、九列行明细、合计、未结项（状态、未结余额）、核销记录、调整记录。Esc 或“关闭”回到原按钮，筛选、已加载页和滚动位置保持。读取失败可重试；404 只提示“发票不存在或已不在本公司。”。对话框不写地址栏，教学开启时有教学卡片（#199、#200；`TradeInvoices.tsx:1286–1297`、`TradeInvoiceDetail.tsx:88–126`、`:186–192`）。
- **侧栏分组更清楚**：原“总账”组拆成“凭证与业务事件”“贸易往来”“总账与结账”，共 5 个具名组；16 个链接的文字、顺序、目标不变。390 宽及以下组标题仍隐藏（#197；`App.tsx:205–237`）。
- 证据（来源：PR 正文）：#197、#199 在真实 Chrome 的 PR 取证 head 上跑过端到端与截图；这不是合并后的 squash 提交上的结果。

## 已知限制

- **旧账迁移（M2）仍未完成**：M2-05（演练）与 M2-06（切换）未开始，另需用户授权。
- **详情是只读的**，没有深链接，不自动刷新（每次打开才读取）；404 不重试。
- **390 宽行明细在容器内横向滚动**。
- **性能预算（PG-05，gzip-9）**：#199（base `2a2dca1` 对 head `a8c4968`）入口 +10 B、发票路由块 +2447 B、发票页 CSS +228 B；#197 入口 +128 B、CSS 0 B。基线不同不能相加，与 v0.10.0 相比的净变化未测量，数字取自 PR 正文，发布前未重测。

- 真实 Chrome 的验证在 PR 取证 head 上，不在合并后的 squash 提交上。
- Demo 记录与截图：Demo PR 合并后补链接（docs/demo/v0.11.0）。
