# AI Native ERP v0.13.0（发布说明草稿）

> **草稿，未发布。** 发布日、tag 目标由协调者授权后确定。产品代码基线为 main `ef0de69`（REFAC-01b [#224](https://github.com/lingshf/ai-native-erp/pull/224) 的合并提交；main Full run 45201528305 绿）；其后的 `f1536e1` 只是 v0.12.0 Demo 文档，`git diff ef0de69 f1536e1 -- packages scripts` 为空。自 v0.12.0 的 tag 目标 `a7e2d99` 起，`packages/` 下共 43 个文件（+5679/−3385），`scripts/` 下 3 个文件（+421/−45）。**tag 目标**按 D21 / D398：只有 `git diff f1536e1 <目标> -- packages scripts` 为空，才可打在 RC PR 的 squash 提交上。完整变更对比：v0.12.0...v0.13.0（打 tag 后补链接）。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 minor（0.12.0 → 0.13.0）：新增用户可见功能；**无迁移**（仍为 019），无依赖变化，不改过账规则。

## 亮点

- **订单筛选写进地址栏**：应用筛选后地址带上 `party / side / invoicing / from / to`（和 `company`），刷新、书签、转发链接都能恢复同一批订单。只替换当前地址，不增加浏览器历史、不弹离开确认、不清掉订单草稿。链接里的筛选无效时整组忽略并提示，可一键清除。订单详情的数量、已开票数量、单价、折扣加千分位（TORD-07，#223）。
- **旧账导入多了命令行演练**：`legacy-import --snapshot-dir DIR --dry-run` 只读，不写任何目标库；新的[迁移操作手册](../migration-runbook.md)写明门槛、命令、错误码和回滚。**只在虚构夹具上验证，没有连接真实旧账**（M2-05a，#227）。
- **导入更快、更省内存**：期初未结项校验在 10 万条规模下由估算约 9 小时降到约 27 秒（D430）；期初分批在单一事务内写入，Bench 中导入峰值内存 566.3 → 426.8 MiB，回到 512 MiB 预算内（M2-05b，#232，D434）。

## 需要注意的行为变化

- **订单筛选刷新后保留**：v0.7.0 起订单筛选不会被记住；v0.13.0 起应用的筛选写入地址，刷新或书签恢复。没有点“应用”的草稿输入不进地址。
- **切换账套仍有确认**（D423），与此前一致。

## 与 v0.12.0 相比的显示变化（旧 → 新）

| 位置 | v0.12.0 | v0.13.0 |
| --- | --- | --- |
| 订单筛选 | 刷新后清空，地址不变 | 应用后写入地址，刷新与书签恢复 |
| 链接里的订单筛选无效 | — | 整组忽略，提示“链接中的筛选条件无效，已忽略；当前显示全部订单。”和“清除” |
| 订单详情数量 / 已开票数量 / 单价 / 折扣 | 原样字符串 | 按语言千分位，小数位不变 |
| 订单页教学说明（筛选） | 筛选不被记住 | “筛选保存在地址中，刷新或复制链接后保持” |

## 面向调用方（HTTP API、CLI、迁移）

- **CLI**：新增 `npm run storage:admin -- legacy-import --snapshot-dir DIR --dry-run`；选项不全或同时给 `--target` 按用法错误拒绝。其余命令、参数、错误码不变。
- **迁移 / API / 依赖**：无变化。

## 已知限制

- **旧账迁移（M2）仍未完成**：演练只在虚构夹具上验证；真实旧账的演练和切换（M2-06）需用户另行授权，未开始。
- 订单筛选地址不记游标与每页条数；筛选任一项无效则整组忽略；开票状态只能单选。
- **性能预算（PG-05，gzip-9，取自 PR 正文）**：TORD-07 入口 +0.034 kB、订单页（含共享块）+0.773 kB、CSS 0，发票页 −0.101 kB。导入 Bench 为 Linux CI 实测（run 45196607138）。与 v0.12.0 相比的整体净变化未测量。
- TORD-07 按 D418 / D375 / D406 以 jsdom 与 CI 验收，没有真实 Chrome 截图。
