# AI Native ERP v0.3.0 — Release 说明草稿

> 草稿，待协调者授权后创建 tag 与 GitHub Release。UI-1 界面改进 Sprint（13 项）完成，版本号依据 D66（新增界面能力，SemVer 次版本）。产品代码基线为 main `c7e5783`（#82），自 v0.2.0（`037b3ce`）以来合并 25 个提交。按 D21，tag `v0.3.0` 打在本发布 PR 合并后的 squash 提交上。CHANGELOG 日期 2026-11-19。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

## 亮点

- **全站新界面（UI-01..UI-08）**：深色品牌顶栏、分组侧栏、统一的页头 / 命令栏 / FastTab / KPI 卡 / 徽标（颜色加符号）/ 消息条。窄屏与粗指针下点击区 ≥ 44 px，390 px 宽无横向溢出。行为、接口与校验不变。
- **更多页面有教学说明**，关闭后只隐藏教学卡片；边界说明与风险提示始终显示。AI 面板的“仅为候选，需人工确认。”始终可见。
- **凭证草稿**分“常规”“分录行”两区，带借贷合计和“借贷不平”提示；**期末结账**新增期间列表。
- **旧账迁移前段**：导入期初未结项（`--opening-items`，M2-03b）、导入后自动核对与 `legacy-reconcile`（M2-04）、只读“迁移核对”页、GL 核对新增“期初”列与 P 公式（M2-04b）。
- 修复：发票页 Alt+Shift+N 偶发被忽略（FLAKE-01）；账龄 / 历史余额在大量核销历史下更快（迁移 016）。
- CI：Full 浏览器分片重平衡（5→9），每片目标 ≤ 25 s（R6/R6b）。

## 已知限制

- **旧账迁移（M2）尚未完成**：M2-05（演练）与 M2-06（切换）未开始，另需用户授权；迁移核对页只读，核对通过不等于允许切换。
- **真实迁移演练时，用户需提供期初未结明细文件**。只要导入范围含 AP/AR 控制科目就必须提供，即使各科目都声明为 empty。
- 期初未结项不能开贷项或取消（D30）。
- 非库存订单只有 API，没有录入界面（M1-R1）。
- 保存期间准入成功后提示仍沿用“原操作已成功…”措辞。
- 随版本提供的截图由虚构夹具生成，不是真实账套数据。
- 日志：服务端 `http_error` 的 `errorType` 现区分 `DomainRejection`（领域 / 存储 4xx）与 `HttpError`；如有按旧值（`ParseError`）过滤日志的脚本需更新。
