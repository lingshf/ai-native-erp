本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 minor（0.18.0 → 0.19.0）：TLIST-04 让财务维度页多了一个按钮，是用户可见的小功能。**无迁移，无依赖变化**，已有账套不需要 migrate，不改过账规则与任何金额、数量口径。

## 亮点

- **财务维度页多一个“刷新列表”按钮**（TLIST-04，[#296](https://github.com/lingshf/ai-native-erp/pull/296)）：在“新建配置”之后（英文 “Refresh list”）。点它按当前公司、类型与上级维度从第一页重新读取列表；所选项和正在编辑的内容保留，不弹确认，编辑器打开时仍可用。Tab 顺序多一站。
- **订单详情内部拆分**（REFAC-11，[#299](https://github.com/lingshf/ai-native-erp/pull/299)）：`OrderView` 的函数体拆到 `trade-orders/` 下的新文件，只搬移，界面与行为不变。
- **测量脚本入库**（MEAS-01，[#298](https://github.com/lingshf/ai-native-erp/pull/298)）：`scripts/measure/` 统一包体积测量口径，只影响开发流程。
