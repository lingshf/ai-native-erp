# AI Native ERP v0.18.0（发布说明草稿）

> 发布候选，尚未打 tag，日期待定。tag 目标按 D484：打在 `release/v0.18.0` 上审核通过的 RC 头，授权前不打。

本地优先、面向小企业的 AI-native ERP，也可用于会计教学（教学说明可关闭）。SQLite、本机单用户、无登录。**非生产演示版。**

版本号取 minor（0.17.0 → 0.18.0）：TLIST-03 让科目表页多了一个按钮，是用户可见的小功能。**无迁移，无依赖变化**，已有账套不需要 migrate，不改过账规则与任何金额、数量口径。

## 亮点

- **科目表页多一个“刷新列表”按钮**（TLIST-03，[#288](https://github.com/lingshf/ai-native-erp/pull/288)）：在“新建科目”之后（英文 “Refresh list”）。点它按当前公司从第一页重新读取科目；所选公司和正在编辑的内容保留，不弹确认，编辑器打开时仍可用。Tab 顺序多一站。
- **订单列表内部拆分**（REFAC-10，[#291](https://github.com/lingshf/ai-native-erp/pull/291)）：`OrderList` 的函数体拆到 `trade-orders/` 下的新文件，只搬移，界面与行为不变。

## 需要注意

- **无需 migrate。** v0.17.0 的账套可直接使用。
- **体积（#288，来源：#288 正文）**：`Accounts` 路由块 gzip-9 3688 → 3775 B（+87 B，上限 +200 B）；首屏 JS 160933 → 160942 B（+9 B，上限 +40 B）。
- **体积（#291，来源：#291 正文 R7）**：订单页块路由 +265 B（预算 +900 B），首屏 ±0，其他路由 ±0，CSS 不变。
- **证据口径**：REFAC-10 的“行为不变”靠 #291 的 R4（7 个场景 base 与 head 逐字节相同），是 jsdom 证明；TLIST-03 的用例同样是 jsdom，不模拟按键。真实 Chrome（Demo，R3 时段，端口 4203，退出码 0，17 项显式检查全部通过，另有 7 条取证记录）：科目表页 1440 中英文与 390 px 截图；390 px 下页面 scrollWidth 为 390，“新建科目”与“刷新列表”同一行且在视口内；焦点从“New account”按 Tab 到“Refresh list”，Enter 与空格各触发 1 次列表请求，编辑器打开时同样 1 次请求且编辑器仍打开；订单列表 1440 中英文有行且筛选栏三个按钮可见。详见 [Demo](../demo/v0.18.0/README.md)。
- 数字取自各来源 PR 正文，发布前未重测。
