## 拍摄内容（`scripts/capture.mjs`）

1. 业务事件（`#/events?company=DEFAULT`，视图“业务事件”与“转账队列”）中英文各一张 1440 截图（红 / 绿主题），“刷新列表”在列表上方。
2. 390 px 中英文各一张：`scrollWidth ≤ 390`，按钮 `left ≥ 0` 且 `right ≤ 390`。
3. 原生键盘记录：Tab 到“刷新列表”，Enter 与空格各触发 1 次请求；草稿编辑器打开时，先在“摘要”输入文字，再从“刷新列表”之前最近的可聚焦元素按一次 Tab 到达按钮，Enter 触发 1 次请求，编辑器仍打开，摘要文字不变。

截图为空列表状态（演示账套没有业务事件）。
