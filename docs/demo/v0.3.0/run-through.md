## 两条控制台错误（均为已知、预期）

- 运行状态页首次加载的 **404**：浏览器请求 favicon，无此资源（服务端日志类型 `HttpError`）。
- 试算平衡表的旧账上下文请求 **503**（`UNAVAILABLE`）：演示账套未配置旧账快照，属预期，页面显示中性提示（服务端日志类型 `InternalError`）。

## 另一独立用例（未与上面的 503 混同）

- 迁移核对 API：只要目标账套已通过 `ERP_SQLITE_FILE` 配置，即使没有旧账快照、尚无核对运行，也应返回 **200 且 `run: null`**（代码见 `packages/infra/src/storage/reconciliation.ts`）。同一个空演示账套上，试算平衡表的旧账上下文接口则预期 **503**。两者是不同接口、不同结果。本次演练**未记录**迁移接口的实际响应，上述 200 / `run: null` 为**代码预期结果**，非实测。
