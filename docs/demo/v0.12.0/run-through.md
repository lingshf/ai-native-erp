# Demo v0.12.0 走查（按用户视角）

演示账套为临时账套，端口 4202；截图见 [README](README.md)。

1. **发票深链接**：打开 `#/trade-invoices?company=DEFAULT&party=PARTY2&side=AP&invoice=<发票 id>`，直接弹出详情（合计 100.00 / 13.00 / 113.00），列表同时按 PARTY2 + AP 筛选。去掉 `invoice` 参数则不弹窗、不发详情请求。
2. **非法链接**：`invoice=not-a-document-id` 提示“找不到”，不发请求、没有重试；格式正确但不存在的 id 会发一次请求，得到 404 和同一句提示。`side=XX` 整组筛选忽略并提示，可点“清除”。
3. **订单按开票状态筛选**：订单列表选“未开票 / 部分开票 / 已开完”，列表只剩该状态的订单，徽标一致。
4. **期末结账与总账页头**：侧栏进入期末结账、科目、财务维度、凭证、业务事件，页头有一句说明；结账页的准入摘要显示“贸易 / 税务”（英文 Trade / Tax）。
5. **大额发票**：筛选 PARTY2 + AP，打开 AP-BIG-1：数量 1,234、单价 1,000,000.12、折扣 12.5；合计 1,079,750,129.57 / 140,367,516.84 / 1,220,117,646.41；390 宽合计排成两行，不溢出。

S12 回顾行动项（D444）：时段运行只允许单次手动启动，禁止自动重试循环；开跑前须确认没有残留 shell。
