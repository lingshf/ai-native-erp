# 用户文档

面向本机单用户的小企业 AI-native ERP，也可用于会计/ERP 教学。以下页面以 `main` 的代码和测试为准。

**版本与变化只看 [CHANGELOG](../../CHANGELOG.md)**（唯一权威，D558）：每个版本改了什么、是否需要迁移、哪些是用户可见的变化都在那里；本页和各用户页不再复述版本叙述。各页内“vX.Y.Z”标注只说明该功能从哪个版本起可用。系统全部文档的入口见 [docs/README.md](../README.md)。

| 文档 | 内容 |
| --- | --- |
| [快速上手](getting-started.md) | 启动、账套、界面布局、首次进入看到什么 |
| [界面指南](ui-guide.md) | 新外壳、页面模板、窄屏与可访问性；之后各版本的界面小变化按版本顺序排列 |
| [教学模式](teaching-mode.md) | “显示教学说明”开关的作用和边界 |
| [总账](ledger.md) | 科目、维度、凭证、业务事件、报表、结账、AI 助手 |
| [贸易 AP/AR](trade.md) | 期间准入、贸易主数据、订单、发票、付款/收款、预付/贷项/专用纠错 |
| [贸易主路径演练](trade-main-path.md) | 用全新演示账套走完整条贸易路径的步骤、金额和截图 |
| [往来未结项、账龄与 GL 核对](trade-reports.md) | 未结项、账龄、月末历史余额、GL 核对 |

界面流程图见 [docs/flows](../flows/README.md)，各版演示脚本与截图在 `docs/demo/`（目录名即版本号，规则见 [Demo 模板](../demo/TEMPLATE.md)）。

通用原则：预览只读，保存与“确认”是独立动作；AI、教学和偏好都不会自动记账；已过账数据不可修改，只能通过镜像纠错或专用取消反向。

## 已知限制

限制随版本变化，不在此处维护清单：

- 每个页面的“限制”或“边界”小节说明该页当前的限制，以该页为准。
- 某个版本发布时已知的限制，写在该版本的 [CHANGELOG](../../CHANGELOG.md) 条目和 `docs/release/` 下的发布说明里。
- 旧账迁移尚未切换：迁移核对页只读，核对通过不等于允许切换；对真实旧账执行任何一步都须用户另行书面授权，见[迁移操作手册](../migration-runbook.md)。
