# 用户文档（v0.1.0 预览）

面向本机单用户的小企业 AI-native ERP，也可用于会计/ERP 教学。以下文档以 `main@d8fa0bb` 的代码和测试为准。

| 文档 | 内容 |
| --- | --- |
| [快速上手](getting-started.md) | 启动、账套、界面布局、首次进入看到什么 |
| [教学模式](teaching-mode.md) | “显示教学说明”开关的作用和边界 |
| [总账](ledger.md) | 科目、维度、凭证、业务事件、报表、结账、AI 助手 |
| [贸易 AP/AR（预览）](trade.md) | 贸易主数据、发票、付款/收款、预付/贷项/专用纠错 |
| [备份与旧账工具](backup-and-legacy.md) | 备份/恢复、旧账快照、M2 预演的实际可见度 |

界面流程图见 [docs/flows](../flows/README.md)，演示脚本见 [docs/demo/v0.1.0](../demo/v0.1.0/README.md)。

通用原则：预览只读，保存与“确认”是独立动作；AI、教学和偏好都不会自动记账；已过账数据不可修改，只能通过镜像纠错或专用取消反向。

## 已知限制（v0.1.0）

- 未配置旧快照时，“只读报表 → 试算平衡表”返回 503，提示“已验证快照不可用或未配置。请检查服务后重试。”。这不代表当前账套不可用，请使用“总账报表”。
- 凭证页列表为空时会误显示“没有科目。”，并非科目缺失。
- 根 README 仍写迁移“升级到 008”，实际以 012 为准。
