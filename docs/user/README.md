# 用户文档（v0.2.0）

面向本机单用户的小企业 AI-native ERP，也可用于会计/ERP 教学。以下文档以 v0.2.0 对应的 `main` 代码和测试为准（M1 贸易里程碑完成）。

| 文档 | 内容 |
| --- | --- |
| [快速上手](getting-started.md) | 启动、账套、界面布局、首次进入看到什么 |
| [教学模式](teaching-mode.md) | “显示教学说明”开关的作用和边界 |
| [总账](ledger.md) | 科目、维度、凭证、业务事件、报表、结账、AI 助手 |
| [贸易 AP/AR](trade.md) | 期间准入、贸易主数据、发票、付款/收款、预付/贷项/专用纠错 |
| [往来未结项、账龄与 GL 核对](trade-reports.md) | v0.2.0 新增：未结项、账龄、月末历史余额、GL 核对 |
| [备份与旧账工具](backup-and-legacy.md) | 备份/恢复、旧账快照、旧账导入（M2-03，命令行）及其限制 |

界面流程图见 [docs/flows](../flows/README.md)，演示脚本见 [docs/demo/v0.2.0](../demo/v0.2.0/README.md)（v0.1.0 的见 [docs/demo/v0.1.0](../demo/v0.1.0/README.md)）。

通用原则：预览只读，保存与“确认”是独立动作；AI、教学和偏好都不会自动记账；已过账数据不可修改，只能通过镜像纠错或专用取消反向。

## 已知限制（v0.2.0）

- 旧账迁移（M2）尚未完成：按 D26 依次为 M2-04 首批 → M2-03b → M2-04b → M2-05（演练）→ M2-06（切换）；导入范围含 AP/AR 控制科目时必须提供期初未结明细文件，即使各科目都声明为 empty。
- 非库存订单只有 API，没有录入界面；教学提示不覆盖付款、调整、主数据和期间准入页。
- 保存期间准入成功后沿用“原操作已成功；请以当前期间状态为准。”的提示措辞。
- 完整列表见 [CHANGELOG](../../CHANGELOG.md#020---2026-11-19)。

v0.1.0 的三项已知问题（空凭证列表显示“没有科目。”、旧快照未配置时报错、根 README 迁移版本过时）已在 v0.2.0 修复。
