通用原则：预览只读，保存与“确认”是独立动作；AI、教学和偏好都不会自动记账；已过账数据不可修改，只能通过镜像纠错或专用取消反向。

## 已知限制（v0.3.0）

- 旧账迁移（M2）尚未完成：M2-05（演练）与 M2-06（切换）未开始，另需用户授权；迁移核对页只读，核对通过不等于允许切换。
- 真实迁移演练时，用户需提供期初未结明细文件；导入范围含 AP/AR 控制科目时必须提供，即使各科目都声明为 empty。期初未结项不能开贷项或取消。
- 非库存订单：v0.3.0 只有 API，没有录入界面；v0.3.0 之后的 main 新增“采购 / 销售订单”录入页（M1-R1a #91）。
- 完整列表见 [CHANGELOG](../../CHANGELOG.md#030---2026-11-19)。

v0.2.0 的限制中，“Full 有一片约 147 s”已由 R6/R6b 处理；“教学提示不覆盖付款、调整、主数据和期间准入页”已由 UI-04/UI-06/UI-07b 补上教学说明。v0.3.0 中“保存期间准入后沿用‘原操作已成功…’措辞”的限制已由 UI-10g（#94）改为“贸易期间准入已保存。”（v0.3.0 之后的 main）。
