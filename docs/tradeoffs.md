# 取舍汇总

按主题汇总已记录的设计取舍：备选、理由、代价、失效条件。**本页只做导航和归纳，不复述原文**：决定原文以链接的 ADR、[路线图 §6](../design/roadmap.md#6-决定记录)和[决定索引](../design/decisions.md)为准，冲突时以原文为准。某一项在原记录中没有写明时，本页标“原记录未写”，不替它补写。本页没有新增任何决定。

## 1. 只做 SQLite、本机单用户

- 原文：[ADR-LOCAL-001](../design/adr/ADR-LOCAL-001.md)（D560），方向来自[路线图 §1](../design/roadmap.md#1-不变的产品方向)；取代 [ADR-SME-001..006](../design/adr/ADR-SME-001.md) 中的双库、Server、OIDC 部分。
- 备选：SQLite + PostgreSQL 双库；Server 档案 + OIDC + 多用户批准；先做 Server 再降级出本机版。
- 理由：目标用户是本机单用户的小企业，第二种数据库和身份体系没有对应的用户价值。
- 代价：不支持多人或远程使用；同步的 better-sqlite3 在 worker 被占满时请求排队，要靠基准观测；将来要 Server 须重新设计身份与并发，不是打开开关。
- 失效条件：多人/远程/多设备需求；实际或合成数据量下 SQLite 超出已测性能预算，**且**索引与期间余额表都不能解决（二者缺一不可）；出现登录、分权的合规要求；单文件无法满足备份与保留要求（ADR 列出的 4 条）。
- 相关：运行与备份见[运维页](operations.md)。

## 3. AI 助手只产出候选，不保存、不过账

- 原文：[路线图 §1](../design/roadmap.md#1-不变的产品方向)“AI 只建议，不保存、不过账”（产品意图的源头）；实现依据：[AI 助手事实清单](../design/ai-assistant-facts.md)（F1–F12）、D560（取代 ADR-SME-005 的 AI 部分）；说明见 [AI 助手](ai-assistant.md)。
- 备选：**原记录未写**（没有记录过被比较的备选方案；本页不代为列出）。本页只能说明现行做法：会话关闭全部工具，输出只能填入新草稿，仍由用户保存、预览、过账（F10、F21–F25）。
- 代价：多一步人工；模型没有工具，只能依据请求时发送的上下文（含财务数据，会离开本机）作答。
- 未解决：环境变量去掉三个键后交给 SDK 工厂，SDK 子进程是否收到、是否应改白名单未验证（F22，SEC-01 候选）；Copilot 服务端的数据处理，事实清单 §6 列为缺口。

## 4. 教学模式只限制界面，服务端不拦截讲解

- 原文：D563（[S24 决定表](../design/tasks/S24.md)）；事实见 [AI 助手 §4](ai-assistant.md#4-教学模式)。
- 现行做法：关闭教学模式时隐藏“讲解”并中止进行中的请求；服务端不检查。
- 失效条件（D563 已写）：出现多用户、教师锁定或远程访问时重新评估。
- 代价：它不是访问控制；直接调用接口不按教学模式过滤（其他 HTTP 防护，如本机边界检查、方法与内容类型限制，仍然适用，见 [AI 助手 §2](ai-assistant.md#2-数据流)）。
