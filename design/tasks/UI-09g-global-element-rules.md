- Sprint：S4　依赖：[UI-09a](UI-09a-components-css.md)、[UI-09b](UI-09b-shell-brand-css.md)、[UI-09c](UI-09c-master-css.md)、[UI-09d](UI-09d-ledger-period-close-css.md)、[UI-09e](UI-09e-journals-css.md)、[UI-09f](UI-09f-trade-css.md)、[UI-10a](UI-10a-shell-preference-messagebar.md)（外壳串行最后：M1-R1a → UI-09b → UI-10a → UI-09g）　建议分支：`ui-09g-global-rules`
- 冲突域：web-ui:shell（**只改 `src/styles.css`**）。不改页面或组件 CSS，所以不占用其他冲突域。证据覆盖全部页面，所以开工时不应有正在进行的页面 CSS 任务；若 rebase 后 main 上有新的页面 CSS，重做证据。
- 类型：**只改 CSS**
- 来源：[UI-1 审查](../reviews/UI-1.md) §6 D-7，方法见 §5.1（C4 属性级证据）

## 范围

- `styles.css` 中的全局元素规则 `button`、`select`、`table`、`th`、`td` 等（main `2a23025` 的 `styles.css:6-72` 一带）。
- 方法（**只删已证实可删的部分**）：
  1. 逐页、逐元素列出这些全局规则中每个属性在各页的实际效果：被哪条页面或组件规则覆盖，或仍然生效；
  2. 一个属性可删的条件：在全部采集点上，删除前后计算值逐项相等。这包括被覆盖的属性，以及与浏览器默认值相同的属性；
  3. 只删除可删的属性。删掉全部属性后变空的选择器也一起删除；
  4. 仍然生效的属性**原样保留在 `styles.css`**，本任务不把它们迁到页面或组件 CSS。在证据表中逐条列出这些属性，注明归属的冲突域，作为下一 Sprint 的迁移待办。
- 不接手任何页面，不改页面 / 组件 CSS 或 `.tsx`。

## 验收标准

1. 满足 [UI-1 通用验收标准](README.md#ui-1界面逐步改进) 1–9。PG-05：入口 JS 不变，CSS 合计**不增**（应减少），路由 chunk 不变。
2. **属性级证据表**：格式同 [UI-1.md §5.1](../reviews/UI-1.md)。表中写明页面、元素、属性、删除前计算值、删除后计算值、覆盖来源，以及处理方式（删除 / 保留 + 归属冲突域）。
   - 用 `getComputedStyle` 脚本对全部导航路由（含运行状态页）、两主题、1440 / 390 采集；
   - 删除前后计算值逐项相等，才算“完全覆盖”，才允许删除。
3. 全部页面改前 / 改后截图像素差为 0。因为只删除计算值不变的属性，任何非 0 差异都说明删多了，应恢复该属性，不申请豁免。
4. **证据归档**：开发者把证据表写入 PR 描述，并附上采集脚本及其 JSON 输出（作为 PR 产物，或放在 `design/` 以外的脚本目录）。开发者**不改 `design/`**。合并后，由设计角色在任务表同步的文档 PR 中，把证据表摘要追加到 `design/reviews/UI-1.md` §5（新增小节，不改已有结论），并把“保留”项登记为下一 Sprint 的待办。
