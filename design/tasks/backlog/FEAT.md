# 新功能候选（D641）

供 S34 及以后选题。顺序由 Product/Design 按 [OQ-01](../../requirements.md)（成本与税的计算器先于依赖它们的交易）、[路线图 §3“之后”](../../roadmap.md)（M2 之后按 OQ-01 顺序：库存与成本、税、外币、银行……）和小企业主流程的价值排定；按 M2 授权由 PO 与 TL 自定。每项开工前先写设计或任务书，并按 D557 写设计期质量项（UI、性能、迁移）。本表只排顺序，不是已批准的范围；单项实施仍按“一个任务 = 一个分支 = 一个 PR”。

现状（main `d83a006`）：M1 已做非库存贸易（伙伴、费用采购与服务销售发票、订单与从订单开票、付款收款与核销、预付预收、贷项、账龄与 GL 核对）。共享税计算器已有（FR-T02），只支持普通税、零税、免税；发票币种必须是会计币（FR-T02）；库存、外币不存在（`design/requirements.md:34`）。
