# M1-R1 非库存订单录入 GUI

- 里程碑：M1 评审后续　依赖：M1-R　建议分支：`trade-order-entry`
- 冲突域：web-ui:trade
- **阻塞 v0.2.0：否**

## 背景

M1-03 的采购/销售订单只有 API。E2E（`packages/infra/test/http/trade-gui.slow.test.ts`）和 README 主路径都用 API 建 PO，用户在 GUI 中无法录入订单，订单匹配只能靠外部调用。见 [M1 评审 §6](../reviews/M1.md)。

## 范围

- Web 新增订单录入与列表：伙伴、行（商品、税码、数量、单价、折扣），复用 M1-02 计算器的服务端预览结果显示金额，不在客户端算税。
- 只用现有订单 API，不改后端规则和表结构。
- 列表 >100 行虚拟滚动；未保存输入离开守卫；中/英、红/绿、键盘；教学模式下有简短说明。

## 验收标准

1. 纯键盘可录入并保存一张 PO，然后在发票页按订单行匹配开票。
2. Web 测试覆盖：保存、校验错误显示、离开守卫、中英键一致。
3. E2E 主路径改为用 GUI 建 PO（只在 Full 层）。
4. CI 绿。

## 性能考虑

首屏 JS 不增加（页面懒加载）。
