1. **MCF-01**（P1）：Release 补 CHANGELOG；非作者 Reviewer 逐条对照已合并的 diff。

3. **MCF-17**（P2）：Reviewer/QA 补 REFAC-31/34 的 R8b 场景与测试、真实 Chrome 证据的映射；缺证据记为“未确认”。
4. **MCF-05**（P2）：新的只读 Developer 会话对照 `70acd04` 复核 SEC-02 对 F22、§6.3 与 `docs/ai-assistant.md` §3/§5/§7 的改写；Product/Design 核对与 D570/D571 措辞一致。先出只读复核记录。修正按所属目录分开：`design/ai-assistant-facts.md`（F22、§6.3 等）属 `design/`，由 Product/Design 修改；`docs/` 下的页面（如 `docs/ai-assistant.md`）并入第 7 项的 KL 文档批次（与 MCF-06 同改 `docs/ai-assistant.md`）。
5. **MCF-02**（P2）：MCF-01 合并后，Release 从当时的 main 新切 RC，旧 RC `3566ddb` 标为已取代。
6. **MCF-14**（P2，Product/Design）：决定索引生成脚本入库，`design/decisions.md` 开头写明重新生成的命令；在该提交上重新生成结果一致。
