# M2-03 导入执行（写入新的目标库）

- 里程碑：M2　依赖：M2-02、M0-R1　建议分支：`legacy-import-execute`
- 冲突域：migrations(014)+migrations.ts, domain-posting, storage, admin-cli
- **开工门禁**：M0-R4、M0-R5 都已合并（M2-01、M2-02 显式依赖两者，其余 M2 任务经依赖传递继承）。
- **数据**：开发、CI 和 Bench 只用虚构夹具。对真实旧账（4173 原账套、ID3 草稿、旧 checkout）的任何操作都需要 README“待用户决定”中对应的授权，本任务的开发与验收不需要真实数据。
- **真实导入**：需要决定 A（演练）或 B（切换），并且决定 C 已确认；C 未确认前只能对真实快照做 dry-run。

## 迁移编号

- 014 必须排在 M1 的 010–013 之后合并。M2-03 先就绪时等待 013 合并，**不适用**通用的未合并编号互换规则。
- `domain-posting` 冲突是独立的开发约束：与 M1-03、M1-06 不能同时开发，不因迁移串行集成规则而豁免。

## 范围

- 迁移 `packages/infra/migrations/sqlite/014-legacy-import.sql`：
  - `legacy_import_runs`：快照 SHA、决定 C 的选项摘要、迁移版本、状态（`importing`/`imported`/`reconciled`/`failed`）、进度游标、计数；
  - `legacy_refs`：旧对象类型 + 旧 ID → 目标 ID，唯一约束。
- `legacy-import --snapshot-dir … --target <路径> --drafts … --receipts …`（选项同 M2-02，必须显式）。
- **目标库**：
  - 路径不存在：新建库、跑全部迁移、写 run 行后开始导入。
  - 路径已存在：只有同时满足以下条件才续跑，否则一律拒绝且不修改目标：库里恰好一条本工具创建的 run，状态为 `importing`；快照 SHA 和选项摘要与本次相同；迁移版本等于当前最新版本；除 run 表、`legacy_refs` 和已记录进度内的导入数据外，没有其他业务数据。
  - 任何时候都不导入已有业务数据的库，不合并、不覆盖。
- **原子批次**：每批（≤ 5000 分录）的业务行、`legacy_refs` 和 run 进度在同一个事务里提交；中断后续跑从进度游标继续，结果与一次跑完相同。
- **历史导入入口**：写入复用领域过账管道（凭证平衡、期间、控制科目规则；导入适配器按 M0-R1 登记），不另写绕过校验的 SQL。
- **关闭期间的处理顺序**：
  1. 先按源建立全部期间，统一为开放；
  2. 按日期顺序导入全部凭证，走正常的开放期间校验；
  3. 全部凭证写完后，在最后一个事务中通过 M0 的期间关闭路径，把源中关闭的期间关闭。
- **隔离**：导入全程持有 M0-R5 的独占维护锁；run 状态不是 `reconciled` 时，运行时拒绝把该库作为活动库打开。
- 导入完成状态为 `imported`；由 M2-04 核对后更新。

## 不做

不做增量同步；不双写；不碰 4173 与旧 checkout。

## 涉及文件

`packages/infra/migrations/sqlite/014-legacy-import.sql`、`packages/infra/src/storage/migrations.ts`、`packages/core/src/**/journals*`（导入入口）、`scripts/storage-admin.mjs`、新增导入集成测试。

## 验收标准

1. 虚构夹具快照导入后：目标库每月每阶段试算、科目余额、凭证/分录数、维度合计与源一致；草稿按选项处理；`legacy_refs` 覆盖每个导入对象；关闭期间在导入后为关闭。
2. 在第 N 批事务提交前强制中断后续跑：结果与一次跑完相同，没有重复，也没有缺失。
3. 拒绝续跑：快照不同、选项不同、迁移版本不同、目标含其他业务数据、目标不是本工具创建的；都不修改目标和源。
4. 缺少决定 C 选项、快照校验失败：拒绝。
5. 评审检查：没有绕过过账规则的新写入路径。
6. 升级 CI 覆盖：从紧邻的上一版本 013 升级到 014，以及从 007 完整升级到 014。

## 性能考虑

预编译语句、按批事务、不临时删建索引。Bench：100 万 GL 行导入 ≤ 10 分钟，峰值 RSS ≤ 512MB；导入后热读预算与 M0 相同（试算 p95 ≤ 1s）。
