# M0-R M0 里程碑评审 + 测试审计（设计角色）

- 里程碑：M0　依赖：M0-15（及 M0-06、M0-07）　执行者：设计角色

## 内容

1. 代码是否按 [M0 架构](../m0-architecture.md) 完成：3 包与目录边界、TS 源码直跑、纯 Fastify、无 PG、WAL、统一账模型。
2. 设计原则：SOLID 但不过度设计（无单实现的抽象层、无未使用的扩展点、无重复逻辑）。
3. 性能：读取每晚 bench 结果（100 万 GL 行热读 p95 ≤ 1s、≤100 行预览/确认 p95 ≤ 2s），首屏 JS 体积基线。
4. 测试审计：CI 总时长（PR/main/每晚）、最慢 10 个测试、重复/低价值用例、本月 Actions 分钟用量。
5. 路线图 M0 出口标准逐条核对。
6. 依赖更新链路：lockfile 只含公共 registry 地址、防回归检查在 PR CI 生效、Dependabot npm 更新正常（M0-06a）。

## 产出

- 评审结论写入 `design/reviews/M0.md`（新），问题生成子任务 `M0-R1`、`M0-R2`… 加入任务总表。
- 根据审计调整 CI 预算或分层（如有）。
