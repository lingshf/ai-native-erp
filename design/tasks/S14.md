### 范围与决定

1. **导入方改为直接导入**：9 处导入方把说明符从 `Journals.tsx` 改为 `journals/dialogs.tsx` 或 `journals/virtual-rows.tsx`。导入名、是否 `import type`、语句位置都不变。同一条语句的共用件来自两个模块时，可以拆成两条 `import`，放在原语句的位置。

3. **样式不随 JS 一起掉出**：每个路由加载的 CSS 集合、顺序与字节都不变（Q4c），也就是说 `journals.css` 仍须进入四个非凭证路由。开发从下面两种做法里选一种，写进 PR 正文：

   - (b) 其他只改导入语句的等价做法。

   不在页面文件里新增 CSS 导入，不改任何 CSS 文件内容。如果三个报表页其实用不到 `journals.css`，删掉这层依赖是另一项优化，不在本任务。两种做法都无法使 Q4c 成立时，先停下报设计角色。
