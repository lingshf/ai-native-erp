# M1-07 贸易 GUI 端到端验收与性能基准

- 里程碑：M1　依赖：M1-06　建议分支：`trade-e2e-bench`

## 目标

完成原 TASK24 的 GUI 验收（在新架构上）并验证贸易性能预算。

## 范围

- 端到端（真实浏览器，`*.slow.test.ts`，只在 main/每晚层）：主数据 → 采购发票（含 PO 匹配）→ 部分付款含折扣 → 预付应用 → 销售发票 → 贷项 → 取消 → 账龄与 GL 核对；中/英、红/绿主题、纯键盘完成一条主路径。
- 基准：在 1M GL 行基础上生成 1000 伙伴、10 万未结项；测量未结项列表首页、账龄、历史余额、≤ 100 行发票预览/确认的 p95；接入 `bench.yml`。

## 验收标准

- 端到端测试在完整层通过；PR 层不运行。
- 热读 p95 ≤ 1s、预览/确认 p95 ≤ 2s，或如实记录差距，由设计角色生成子任务。
- 用户可在本机按 README 步骤完成主路径（PR 描述附截图）。
