# M1-06 未结项、账龄、历史余额与 GL 核对

- 里程碑：M1　依赖：M1-05　建议分支：`trade-open-items-ageing`

## 目标

实现 [FR-T08](../requirements.md) 的查询部分。

## 范围

- 查询供应商/客户未结项、当前余额、月末历史余额（as-of，不受未来核销或当前配置影响）、到期与账龄分段、来源/凭证/核销详情。
- 与 GL 核对：按保存的控制/预付科目汇总，与同范围 GL 比较；其他来源/差异单列，不自动抹平。
- 期间模块准入：trade/tax 模块进入期间准入，已有期间不自动打开新模块。
- web：未结项/账龄/核对页面（虚拟滚动、下钻到单据和凭证）；中/英、红/绿、教学开关、未保存输入/迟到响应保护；贸易数据不自动发送 AI。

## 验收标准

- FR-T08 每条规则有测试；历史余额用“先录后核销”样例验证 as-of 不变。
- 核对差异单列的样例测试。
- CI 绿。

## 性能考虑

历史余额 = 未结项原额 − as-of 日之前的核销合计，用 `settlements(open_item_id, accounting_date)` 索引 SQL 聚合，不重放事件、不建缓存；先测，若 M1-07 基准不达标再由设计角色生成子任务。

## 测试要求

application 层为主；Web 测一个下钻路径。
